## Features

- **今晚的账单**：首屏三行账——一场球花掉什么（支出）、今晚能存回什么（回账）、哪些是无效支出
- **现金流 72 小时**：刚下场 / 回家当晚 / 第二天 / 48–72h 四个时段的记账清单，按时点路由
- **账目分级**：14 项恢复手段 A–D 循证审计（睡眠 A / 力量训练 A / 蛋白质 A / 静态拉伸治酸痛 D / 酒精 D…），可按等级筛选
- **坏账清单**：排酸跑、30 分钟蛋白质窗口、筋膜枪打散结节、贴着膏药上场、出汗排毒、赛后桑拿
- **跟腱专项**：致命区 2–6cm、6–10 倍体重负荷、2/3 断裂者事前无痛；红绿灯信号、数字红线、膏药时间表（上场前 8–12h 停贴）、Alfredson 离心方案
- **复利账户**：肌少症每十年 −3~8%、蛋白质 1.6–2.2g/kg、HRV 正确读法（深睡低值正常、晨起单点测量、只看趋势）
- **年度审计**：5 分钟 4 项自检（慢速单腿触椅起坐 / 闭眼单腿提踵 / WBLT / 单腿臀桥）
- **足部小额**：老茧 vs 鸡眼、跑者趾甲 vs 灰指甲、马拉松系带法
